02How it works

FPS conversion without interpolation

FPS (frames per second) conversion changes how fast a video plays back. Unlike AI-powered frame interpolation tools that generate new frames, Free-FPS simply adjusts the playback speed of your existing frames. No artificial frames are created, only the timing changes.

2×30 fps to 60 fpsplays twice as fast
0.5×60 fps to 30 fpsplays at half speed
1.25×24 fps to 30 fpsslightly faster

Video compression without changing FPS

Keep the original FPS and use the quality controls to reduce file size:

  • CRF (Constant Rate Factor): from 0 (lossless) to 51 (maximum compression)
  • Automatic bitrate: the app picks settings based on resolution
  • Same playback speed, just a smaller file
  • Archiving: save storage while keeping acceptable quality
  • Web: smaller files for faster uploads and streaming
  • Batch compression of many large videos at once

File size reduction comes from compression settings (CRF/bitrate), not from changing FPS.

Common use cases

  • Speed up slow-motion footage: bring 120fps or 240fps recordings to normal playback speed
  • Match frame rates for editing: convert all clips to the same FPS for a smooth timeline
  • Time-lapse effects: raise FPS to make a video play faster without re-recording
  • Fix playback speed: correct videos recorded at the wrong frame rate
  • Compress videos: keep FPS and use CRF or bitrate to shrink the file
  • Platform requirements: hit the FPS a streaming platform or editor expects

07FAQ

What's the difference between FPS conversion and frame interpolation?

FPS conversion (what Free-FPS does) changes the playback speed by adjusting timing between existing frames. Frame interpolation uses AI to generate new frames between existing ones. Free-FPS doesn't create artificial frames: it simply makes your video play faster or slower, which is useful for time-lapse effects, correcting recording speeds, or matching frame rates for editing.

Can I convert 30fps to 60fps without changing speed?

No, pure FPS conversion always affects playback speed. Converting 30fps to 60fps will make your video play at 2x speed. To keep the same playback speed you would need frame interpolation software, which generates artificial frames. Free-FPS is designed for speed-based conversion: slow-motion footage, time-lapse, or matching frame rates for editing.

What video formats are supported?

All major formats FFmpeg can handle, including MP4, MKV, AVI, MOV, WebM, FLV and WMV. Input and output formats can differ: for example, you can convert an AVI file to MP4 while changing the frame rate.

Does it work with 4K and high-resolution videos?

Yes, from SD to 8K and beyond. Processing speed depends on your computer, but resolution doesn't affect the quality of FPS conversion. You can also limit CPU usage to keep the system responsive.

How does GPU acceleration work?

Free-FPS detects compatible GPUs (NVIDIA GeForce GTX 600+, AMD Radeon HD 7000+, Intel 2nd gen+, or Apple Silicon/Mac with VideoToolbox) and uses hardware encoding for up to 5x faster processing. If no compatible GPU is found, it uses CPU encoding. GPU encoding gives nearly identical quality in much less time.

Is Free-FPS really free? Are there any limitations?

Yes, Free-FPS is free and open source (GPL-3.0). There are no file size limits, no watermarks, no trial periods and no premium features. The project relies on community support and donations.

Do I need FFmpeg installed separately?

No. FFmpeg is bundled with the app on both Windows and macOS, so you can start converting right away.
